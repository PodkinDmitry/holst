# XOD · CHAT 02 — фильтрация и сортировка таблицы YouTube

**Статус:** самостоятельный пакет для Sol, без интеграции с хранилищем XOD и меню. Основа: CHAT 01, ветка `ai-workspace`.

## Контракт

- `mountYoutubeTable300(root,{entries,fields,onApply,view?,onSaveView?})`
- `onApply({ids,key,value}) => Promise<{entries,applied,skipped,failed}>`, получает **все выделенные видимые ID** (включая несовместимые типы).
- `view`: `{filter:null|{op:'and'|'or',children:[группа|{key,op:'eq'|'set'|'unset',value?}]},sort:[{key,dir:'asc'|'desc'}]}`. Одиночный узел-условие в `filter` также поддерживается для удобства импорта.
- `onSaveView(view)` — необязательный callback; снапшот передаётся после каждого завершённого изменения настройки. Может вернуть Promise. При ошибке вид остаётся на экране, можно повторить.
- Чистый вычислитель: `mountYoutubeTable300.computeView(entries,fields,view)` — не читает DOM и не мутирует аргументы; новой глобальной функции нет.

## Семантика

- `set` — непустая строка на **применимом** поле, включая `no`.
- `unset` — только пустое/отсутствующее **применимое** поле; неприменимые поля не совпадают.
- `eq` — непустое заданное значение равно переданному варианту; неприменимые исключаются.
- В сортировке заданные значения по позиции в `options` (обратный порядок при `desc`), затем пустые, затем неприменимые (оба последних класса не меняются местами при `desc`). Неизвестные непустые значения идут после известных, но до пустых.
- Равные значения в пределах всех ключей сохраняют исходный порядок. Исходные записи не сортируются на месте.
- `children:[]` в группе И даёт нейтральный фильтр (показывает все строки); пустая ИЛИ не даёт совпадений.
- Выделение только видимых строк; исчезнувшие из вида ID снимаются. После `onApply` вид пересчитывается.
- Сохранение вида сериализовано для предотвращения перезаписи более нового снимка старым. Сообщение о результате показывается только для последней редакции; callback Sol должен обеспечить устойчивую запись.
- Если `view` и `onSaveView` отсутствуют, поведение редактора CHAT 01 сохраняется. Новый редактор вида работает локально в памяти.
