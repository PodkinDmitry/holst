# CHAT32 — reproducible cumulative Test13 source gate (no product patch)

**Status: published candidate for source-only verification; not installed in SOL's checkout.** Owner: 🟦 CHAT; 🟩 SOL remains release/integration orchestrator. Applies exclusively to source-only XOD Test13, not user boards. Target branch: `PodkinDmitry/holst:ai-workspace` only; neither Work nor `main` is touched.

## Why this deliverable instead of another data-loss patch

Previous CHAT16–31 patches were published as individually isolated deltas. The latest shared run, Test13+CHAT19+CHAT21–31, did **not** include CHAT16–18/20 in a unified staged source. Every additional edit increases the unmeasured merge/regression surface. This package supplies a deterministic **fail-closed integration gate** to reduce that uncertainty without silently integrating any patch. It does not claim a newly found product defect or a browser acceptance result.

## Artifacts

- `cumulative_source_gate.py`: standalone Python 3.10+ orchestrator. Reads the original **private** cleaned Test13 ZIP from a local path, verifies ZIP SHA256, CRC and original `v224/base29.html` SHA256; extracts to a temporary directory; verifies each public patch's **Git blob hash** against the 16-patch manifest from the **live GitHub `ai-workspace`** branch; applies them sequentially with `git apply --check` then `git apply` (no forced three-way rewrite), and fails at the first incompatibility. It parses the actual >1 MB inline JS block and runs `node --check`. Optional `--build` runs `build.py` into the same temporary directory. Optional `--test` runs source-backed CHAT21–31 Node VM harnesses against an unchanged exact-original source and staged source. The original ZIP, HTML and bundles **are never added to the published output**.
- `partial_verification.json`: exact machine-readable results of a **partial** run, generated by the above script, containing only public patch IDs/hashes and test counts. No user profile, board or source content.
- This README: test scope and unresolved limitations.

## Usage (agent/CI with source-only Test13 access)

Run in a separate checkout/workspace **after comparing the active SOL source and lock**. Place genuine patch/harness files under `<patch-root>/chat-NN/<filename>` (or `xod-chatNN-work/<filename>`). No user board ZIP should be supplied.

```sh
# Full intended verification — requires all 16 patch blobs from CHAT16–31.
python3 cumulative_source_gate.py \
  --source-zip /path/to/private/XOD-Test13-source-6429ad6.zip \
  --root /path/to/public/chat-packages \
  --fetch-missing --build --test --report cumulative-result.json

# Explicit *partial* historical replay, if a CHAT19-only private baseline exists.
# This mode will NEVER assert full CHAT16–31 integration.
python3 cumulative_source_gate.py \
  --source-zip /path/to/private/XOD-Test13-source-6429ad6.zip \
  --root /path/to/public/chat-packages \
  --partial-baseline19 /path/to/private/CHAT19/base29.html \
  --build --test --report partial-result.json
```

**FAIL semantics:** nonzero exit code on ZIP/HTML SHA mismatch, any missing or tampered patch, unsafe ZIP path, patch conflict, JS parse error, build error or failed/miscounted Node VM tests. No automatic conflict resolution, no source publication, no writes to `main`. The full mode's CHAT25 harness requires the intermediate CHAT19 baseline generated during staging, not a fabricated/guess source.
