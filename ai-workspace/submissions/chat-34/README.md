## Единственное расхождение: тест CHAT19 и более поздний CHAT25

На полной сборке **неизменённый** опубликованный CHAT19 harness сначала проходит 10 кейсов и падает с `ReferenceError: bselDeleteBusy is not defined`: тест извлекает `bselAct` из окончательного HTML, но не включает добавленное CHAT25 соседнее объявление `let bselDeleteBusy = false;`. Для полного прогона `full_vm_extension.py` формирует **только временную копию** CHAT19 test harness, с **ровно двумя строгими заменами**: объявление mutex в синтетическом VM и проверка `B,A` вместо `A,B`. Другие утверждения CHAT19 (в том числе отказ записи, сохранение исходной доски и числа вызовов) не изменяются.
