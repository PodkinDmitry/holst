## 3. Что сделано во время паузы — CHAT 04

**Готовый пакет:** [ai-workspace/submissions/chat-04](https://github.com/PodkinDmitry/holst/tree/ai-workspace/ai-workspace/submissions/chat-04).

Файлы (подтверждены повторным чтением из GitHub): `xod-youtube-table300.js`, `xod-youtube-table300.css`, `xod-youtube-table300-test.html`, `chat03-to-chat04.patch`, `README.md`.

**Изменения:**
1. Опциональная настройка `view.group: null|{key:string,dir:'asc'|'desc'}`; без поля `group` старый формат `{filter,sort}` сохраняется.
2. Группировка по любому объявленному свойству; варианты идут в порядке `field.options` (или обратно).
3. Группы **заданных** (включая `no`), **пустых** (только применимые), **неприменимых** значений разделены; последние две всегда в конце.
4. Группировка учитывает действующие фильтры и сортировку; порядок внутри групп устойчив. Исходные записи не перезаписываются.
5. Заголовки групп в таблице, число строк, сворачивание и `aria-expanded`; сворачивание сбрасывает выделение скрытых строк. Массовая правка и «выделить всё» — только по видимым строкам.
6. После `onApply` записи перераспределяются по группам; существующие пресеты сохраняют и восстанавливают групповую настройку.
7. Чистый вычислитель без DOM: `mountYoutubeTable300.computeGroups(entries, fields, view)`; `computeView` и прежние адаптеры сохранены.

**Принятые разработчиком допущения, требующие подтверждения SOL при интеграции:** одна группировка по одному свойству; локальное (не сохраняемое) сворачивание; пустые группы скрыты; группировка сохраняется в `onSaveView` через новое поле `view.group`.
