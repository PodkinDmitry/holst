ХОЛСТ — как установить и обновлять (версия 2.21)

ОБНОВЛЕНИЕ — ВСЕГДА ОДИНАКОВО: ПЕРЕТАЩИТЕ ВСЁ
Да, можно просто перетаскивать всё целиком — так и нужно. Выделять и помнить, какие файлы нужны, не надо.
1. Распакуйте holst-app.zip в любую папку.
2. Откройте свой репозиторий github.com/<логин>/holst → «Add file» → «Upload files».
3. Выделите в распакованной папке ВСЁ (Ctrl+A) и перетащите в окно GitHub — файлы и папки целиком:
   index.html, sw.js, manifest.webmanifest, значки, папки shots и tools, holst-extension.zip и этот файл.
   Лишнего там нет; совпадающие файлы GitHub просто заменит.
4. «Commit changes». Через 1–2 минуты обновлённый Холст откроется по адресу https://<логин>.github.io/holst/
   Если открылась старая версия — Ctrl+Shift+R (на телефоне — закрыть приложение и открыть снова).
5. Расширение браузера: в Холсте — шапочка «Обучение» → «Основы» → «Устройства» → карточка расширения → «Обновить».
   Одна кнопка делает всё сама: скачивает, кладёт в папку расширения и перезапускает его.
   Самый первый раз Холст попросит выбрать папку Холста на компьютере. Если браузер не умеет писать в папки —
   «Архивом»: распакуйте holst-extension.zip в ту же папку «Расширение Холста» с заменой и на странице
   расширений нажмите у Холста круглую стрелку.
6. Откройте заново вкладки YouTube и claude.ai (F5) — там заработает новое.

ВЕРСИЯ 2.21 — ЧТО ПОЯВИЛОСЬ И ГДЕ
· Панель объекта: слева «Этот объект», справа «Любой объект». Наведите на категорию — откроется; щелчок закрепляет.
  Сверху строка «что включено» — у каждого «×»: например «Заморожено ×» — разморозить одним нажатием.
· Панель функций разделена на три группы: Доски · OS · Приложение. В OS — две новые кнопки: «Советники» и «Учёба».
· Меню → «Файлы и перенос» → «Хранилище YouTube»: копии, Google Takeout, ярлыки папок.
· YouTube: кнопка настроек ленты — справа от голосового поиска; «скрыть канал» — на обложке.
· Расширение: правый щелчок на любом сайте → «Холст» — всё, что можно сделать с выделенным, ссылкой, картинкой,
  страницей, видео; на claude.ai — «Чат Claude — на доску по итерациям».

GOOGLE ДИСК — ПЕРВЫЙ РАЗ (один раз на аккаунт Google)
Облако вверху справа → «Первый раз: настроить Google Диск с нуля» → шаги в окне. В 4-м шаге добавьте свой
адрес Google в «Test users». Google предупредит, что приложение не проверено: это ваше приложение —
«Дополнительно» → «Перейти на страницу Холст».

GOOGLE ДИСК — В ДРУГОМ БРАУЗЕРЕ ИЛИ НА ТЕЛЕФОНЕ
С нуля настраивать не нужно. Варианты:
· Там, где Диск уже подключён: облако → «Ссылка для другого браузера» → откройте ссылку в новом браузере → «Войти в Google».
· Или раз и навсегда: облако → «Файл настройки для всех браузеров» → положите holst-config.json в репозиторий
  рядом с index.html (так же перетаскиванием). Тогда в любом браузере облако сразу предлагает «Войти в Google».
  В файле только Client ID — это не пароль и не ключ.
Входите всегда одним аккаунтом Google (podkindmitrii@gmail.com): другой аккаунт — другая папка «Холст».
Телефон: откройте Холст в Chrome на Android → меню → «Установить приложение».

РАСШИРЕНИЕ — ПЕРВАЯ УСТАНОВКА
Холст → «Обучение» → «Основы» → «Устройства» → карточка расширения → «Установить» (Холст положит расширение
в «<папка Холста>/Расширение Холста»). В браузере: страница расширений → «Режим разработчика» →
«Загрузить распакованное» → папка «Расширение Холста». Закрепите значок Холста на панели браузера.
Не удаляйте расширение при обновлениях — удаление стирает его виджеты и настройки.
Клавиши: Alt+Shift+H — окно «В Холст», Alt+Shift+S — сохранить страницу сразу (chrome://extensions/shortcuts).

YOUTUBE В «ИСТОЧНИКАХ» (один раз)
console.cloud.google.com → тот же проект, где Client ID Холста → Library → «YouTube Data API v3» → Enable;
OAuth consent screen → Data access → scope youtube.readonly. В Холсте: Источники → YouTube → подключить аккаунт.
Историю просмотров за все годы YouTube через API не отдаёт — её даёт Google Takeout:
takeout.google.com → только «YouTube и YouTube Music» → формат истории JSON → экспорт.
Дальше в Холсте: «Хранилище YouTube» → «Google Takeout» → файлы, архив или ссылка на папку Google Диска.

НЕЙРОСЕТИ
Меню → Нейросеть → «Подключить свою нейросеть»: бесплатно без карты — OpenRouter, Gemini, Groq.
У подключённой — «Ключ до»: Холст напомнит за неделю и за день до окончания ключа.

ПЕРЕНОС ИЗ ДРУГИХ СЕРВИСОВ
Меню → «Файлы и перенос» → «Перенос из других сервисов»: Miro и FigJam (по токену), Whimsical, Notion, TickTick,
папка Google Диска. Whimsical — все доски сразу через «Холст в Claude»:
https://claude.ai/artifact/ByHPqtY4qHEK4843Lh53Ko → Меню → «Перенос из других сервисов» → Whimsical → «Все мои доски».
Нужен коннектор Whimsical в Claude (Настройки → Коннекторы); при первом переносе Claude спросит разрешение.
