ХОЛСТ — установка на свой адрес (один раз, ~20 минут)

1. Зарегистрируйтесь на github.com.
2. Справа вверху «+» → New repository. Имя: holst. Видимость: Public. Create repository.
3. На странице репозитория: «uploading an existing file» → перетащите ВСЕ файлы из этой папки
   (index.html, sw.js, manifest.webmanifest, три иконки) → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
   Через 1–2 минуты доска откроется по адресу https://ВАШ-ЛОГИН.github.io/holst/
5. Откройте этот адрес в Chrome на компьютере → значок установки в адресной строке
   (или меню доски ⋯ → «Установить как приложение»). Появится своё окно и значок на панели задач.
6. В доске нажмите значок облака вверху справа и пройдите шаги «Google Диск» — окно само
   покажет, что и куда вставить.
7. Телефон: в том же окне «Google Диск» скопируйте «ссылку для телефона», откройте её
   в Chrome на Android → меню Chrome → «Добавить на главный экран» / «Установить приложение».
8. Перенос досок из версии в Claude: там меню ⋯ → «Скачать офлайн-версию»;
   здесь меню ⋯ → «Открыть файл доски…» → выберите скачанный Холст.html.

Обновления: новые файлы загружаются в тот же репозиторий так же, как в шаге 3
(старые заменятся). Установленное приложение подхватит их само.

Папка на компьютере: установите «Google Диск для компьютера» — папка «Холст»
появится на ПК и будет обновляться сама.
