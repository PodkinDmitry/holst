ХОЛСТ — обновление и подключение Google Диска

ОБНОВЛЕНИЕ (каждый раз одинаково)
1. Откройте свой репозиторий github.com/<логин>/holst.
2. «Add file» → «Upload files» → перетащите index.html, sw.js и manifest.webmanifest из этой папки → «Commit changes».
   Проверка: на GitHub у index.html размер должен совпадать с файлом из этой папки (как у index.html в этой папке).
   Если открывается старая версия — Ctrl+Shift+R (на телефоне — закрыть приложение и открыть снова).
3. Через 1–2 минуты обновлённая доска откроется по адресу https://<логин>.github.io/holst/

ПОДКЛЮЧЕНИЕ GOOGLE ДИСКА (один раз)
1. Сначала откройте версию Холста внутри Claude и разрешите ей Google Диск, когда Claude спросит.
   Она сама создаст в Диске папку «Холст» и положит туда ваши доски.
2. Потом в приложении нажмите облако вверху справа и пройдите шаги в окне «Google Диск».
   В 4-м шаге добавьте свой адрес Google в «Test users».
3. При входе Google предупредит, что приложение не проверено: это ваше приложение.
   Нажмите «Дополнительно» → «Перейти на страницу Холст».
4. Телефон: в окне «Google Диск» скопируйте ссылку для телефона, откройте её в Chrome на Android,
   затем меню Chrome → «Установить приложение».

Папка на компьютере: установите «Google Диск для компьютера» — папка «Холст» появится на ПК сама.

КОМАНДА: ПРИГЛАСИТЬ ЛЮДЕЙ (на сайте, у каждого свой Google)
1. «Все доски» слева → «👥 Командные пространства» → «+» → название → «Создать».
2. ⚙ у пространства → «Пригласить»: адрес Google, роль → «Пригласить». Google Диск пришлёт письмо со ссылкой.
3. Пока приложение Google не опубликовано: Google Cloud → OAuth consent screen (Audience) → Test users → добавьте адрес.
4. Приглашённый открывает ссылку из письма → «Войти в Google» тем же адресом → пространство появится у него.
Подробно: ☰ Меню → «Как пригласить людей в команду».

ОДИН АККАУНТ GOOGLE (важно)
Каждое устройство синхронизируется с одним аккаунтом Google — входите всегда им (podkindmitrii@gmail.com).
Другой аккаунт — это другая папка «Холст» в другом Диске. Если войти не тем аккаунтом, Холст 2.8+
поставит синхронизацию на паузу и спросит: вернуться к прежнему, перейти на новый (доски сольются по
объектам, без копий) или не синхронизировать. Аккаунт устройства и кнопка «Сменить аккаунт…» — в окне
облака вверху справа. Внутри Claude аккаунт задаёт коннектор Google Диска в настройках Claude.

РАСШИРЕНИЕ БРАУЗЕРА (Chrome, Vivaldi, Comet, Edge, Arc) — 2.9
1. Распакуйте holst-extension.zip в постоянную папку (не удаляйте её потом).
2. Откройте chrome://extensions (в Vivaldi — vivaldi://extensions) → включите «Режим разработчика».
3. «Загрузить распакованное» → выберите папку. Закрепите значок Холста на панели браузера.
4. Значок или Alt+Shift+H — добавить страницу задачей, на доску или и то и другое.
   Правый щелчок по странице, ссылке, картинке — то же быстрее; там же «виджет задач на этом сайте».
5. Холст должен быть открыт во вкладке — если нет, расширение само откроет закреплённую вкладку.
   Если Холст у вас не на podkindmitry.github.io/holst — значок → «Настройки» → адрес Холста.

«ПОДЕЛИТЬСЯ» НА ТЕЛЕФОНЕ (Android) — 2.9
1. После обновления откройте Холст в Chrome на телефоне → меню → «Установить приложение»
   (если уже установлен — удалите значок и установите заново, чтобы телефон узнал про «Поделиться»).
2. В любом приложении «Поделиться» → Холст: текст, ссылки, картинки, файлы — задачей или на доску.
   На iPhone так нельзя: копируйте и вставляйте.

ОТЧЁТЫ ИЗ ЧАТОВ CLAUDE — 2.9
Сохраните навык «Отчёт в Холст» (карточка в чате). В конце любого чата: «отчёт в Холст» —
Claude положит отчёт в «Холст/Входящие» на Google Диске, Холст разложит его в задачник при синхронизации.

НЕЙРОСЕТИ — 2.10
☰ → «Нейросети»: у каждого человека своя. С ключом — ChatGPT, Claude API, Gemini (есть бесплатно),
Groq (бесплатно), OpenRouter, Qwen, Perplexity. Без ключа — «Claude по подписке»: задания уходят
в «Холст/Claude» на Google Диске, в любом чате Claude скажите «задания из Холста» (навык «Задания из Холста»).

НЕЙРОСЕТИ — 2.12
Бесплатно без карты: OpenRouter (модель openrouter/free — сам берёт бесплатную модель, которая умеет
действовать на доске; 50 запросов в день, 1000 — после покупки кредитов на $10), Gemini (Flash-Lite —
около 500 запросов в день), Groq (около 1000 в день). ChatGPT и Claude API — только платно.
В карточке нейросети: «Список ▾» — модели прямо от сервиса (бесплатно/цена, ⚒ — умеет действовать на доске),
«Запасная» — ответит, если основная недоступна, «✓ Проверить» — проверка как в чате, «💰 Цена и лимиты».
Вверху — «Только бесплатное»: платные сети и модели не вызываются.
Под шапкой панели ИИ видно, какая сеть и модель ответили; если модели нет — там же кнопка «выбрать».
Groq ≠ Grok: Grok от xAI — в OpenRouter (x-ai/…) или «＋ Подключить другой сервис» → Grok.

РАСШИРЕНИЕ — ОБНОВИТЬ ДО 2.13
Распакуйте новый holst-extension.zip в ту же папку (с заменой) → chrome://extensions → у Холста «↻ Обновить».
Что даёт: число непрочитанных уведомлений на значке расширения и запросы к нейросетям, которые
браузер не пускает напрямую (например, запуск рутины Claude) — расширение передаёт их само.

CLAUDE ПО ПОДПИСКЕ «ПОЧТИ ВЖИВУЮ» — РУТИНА CLAUDE CODE (Pro, Max, Team, Enterprise) — 2.13
Обычный «Claude по подписке» ждёт, пока вы в чате Claude скажете «задания из Холста». Рутина делает это сама:
1. Откройте claude.ai/code/routines → «New routine».
2. В Холсте: ☰ → «Нейросети» → «Claude по подписке» → блок «⚡ Почти вживую» → «⧉ Скопировать инструкцию для
   рутины» → вставьте её в рутину. Подключите коннектор Google Drive. Если просит репозиторий — любой, хоть пустой.
3. В рутине добавьте триггер «API» → скопируйте адрес (…/routines/trig_…/fire) и токен (sk-ant-oat01-…,
   показывают один раз).
4. Вставьте адрес и токен в Холст, включите «Запускать Claude сразу после каждого вопроса» → «▶ Запустить сейчас».
5. Можно добавить рутине и расписание (например, каждые 3 часа) — ответы придут, даже если запуск не прошёл.
Лимит запусков рутин в день: Pro — 5, Max — 15, Team/Enterprise — 25. Один запуск отвечает на все
накопившиеся задания. Обычно ответ приходит за 1–3 минуты.

CHATGPT PLUS, CLAUDE, GEMINI ПО ПОДПИСКЕ — КОПИРОВАТЬ И ВСТАВИТЬ — 2.13
У ChatGPT нет официального способа запускать задачи по подписке извне, поэтому — так:
1. ☰ → «Нейросети» → выберите «Подписка через копирование» (⇄).
2. Спросите в «ИИ на доске» как обычно — Холст сам скопирует запрос с контекстом доски и откроет окно.
3. Вставьте запрос в чат ChatGPT (или Claude, Gemini, Perplexity), скопируйте ответ целиком, вставьте в окно
   Холста → «На доску». Стикеры, рамки, задачи из ответа встанут на доску — фиолетовыми, их можно принять или откатить.
Удобнее: в ChatGPT создайте проект (или свой GPT) «Холст» с инструкцией «Всегда отвечай одним JSON в формате
holst-reply, как в запросе» — тогда ответ всегда готов к вставке. В Claude — то же в проекте.

НОВОЕ В 2.13 — КОРОТКО
• Вкладки: кнопка у названия доски — наведите; Alt+W, Alt+1…9; 📌 — оставить на виду; ⚙ — край, стиль, предзагрузка.
• Команда: одна кнопка с аватарами — кто на доске, «Вести за собой» / «Следовать», курсорный чат («/»),
